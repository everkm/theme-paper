## v0.1.0 (2026-06-28)

**首次发布**

- **博客布局**
  - 从 Astro Paper 迁移的极简响应式博客设计
  - Tailwind CSS v4 设计令牌，支持浅色与深色模式
  - 虚拟首页，含首屏、精选文章与最新文章

- **虚拟页面**
  - 首页（`/index.html`）、文章列表、标签索引、标签文章、归档与关于页
  - 分页的文章列表与标签页

- **文章**
  - 通过首页 `featured` 标签展示精选文章
  - 文章详情页含标签、日期与返回导航
  - 按年月分组的归档

- **功能**
  - 深色模式切换，偏好保存在 localStorage
  - View Transitions 实现站内平滑导航
  - 导航时恢复滚动位置（页面顶部或锚点目标）
  - 配置 `algolia_search` 后，通过 `plugin-in-search` 在顶部提供 Algolia 全文搜索
  - 可选的归档按钮与文章页返回按钮

- **渲染**
  - 服务端代码高亮（`code_highlight.server`）
  - 通过 Typst 的服务端数学渲染（`math_render.server`）
  - 与 Astro Paper 一致的排版样式（引用、脚注、定义列表等）

- **配置**
  - 通过 `everkm.yaml` 配置站点信息、社交链接、版权与文章分页
  - 通过内链从 `_home.md` 与 `_about.md` 引用首页与关于页内容
  - 社交链接在 `name` 匹配已知平台（不区分大小写）时显示内置图标，否则显示文字
