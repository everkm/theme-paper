## Prompt
本更新日志面向终端用户。措辞应友好易懂，避免暴露内部技术细节。

- 更新时请同步维护英文版 `../en/CHANGELOG.md`
- 版本号后的日期为发布日期
- 未指定新版本时，将条目追加到最新版本下


## v0.1.2 (2026-07-25)

**改进**

- 文章列表卡片间距与摘要样式更清晰，窄屏下标题最多显示两行
- 文章页标题字号更协调
- 上一篇 / 下一篇长标题改为单行省略，避免撑乱布局
- 新增 `body_end_html` 配置项，可在每个页面底部追加自定义 HTML，便于接入统计脚本、在线客服等第三方组件
- 多语言站点下，站点信息、导航、分页与搜索等主题配置按当前语言正确生效
- 自动忽略缺少标题或链接的导航项，避免顶栏显示异常

## v0.1.1 (2026-07-24)

**修复**

- 正文图片懒加载：进入视口（含首屏）后会自动加载，不再一直停留在占位图
- 顶栏悬停某一项时，不再让其它导航项一起变色

**改进**

- 提升在较旧浏览器与内嵌网页环境中的样式兼容性
- 顶栏支持 `header_nav` 自定义链接（默认在「关于」之后，可用 `at_before` 提前）
- `about` 可配置为绝对链接，外链默认新窗口打开且不走页面过渡

## v0.1.0 (2026-06-28)

**首次发布**

- **博客布局**
  - 从 Astro Paper 迁移的极简响应式博客设计
  - Tailwind CSS v4 设计令牌，支持浅色与深色模式
  - 虚拟首页，含首屏、精选文章与最新文章

- **虚拟页面**
  - 首页（`/index.html`）、文章列表、标签索引、标签文章、归档与关于页
  - 分页的文章列表与标签页

- **文章**
  - 通过首页 `featured` 标签展示精选文章
  - 文章详情页含标签、日期与返回导航
  - 按年月分组的归档

- **功能**
  - 深色模式切换，偏好保存在 localStorage
  - View Transitions 实现站内平滑导航
  - 导航时恢复滚动位置（页面顶部或锚点目标）
  - 配置 `algolia_search` 后，通过 `plugin-in-search` 在顶部提供 Algolia 全文搜索
  - 可选的归档按钮与文章页返回按钮

- **渲染**
  - 服务端代码高亮（`code_highlight.server`）
  - 通过 Typst 的服务端数学渲染（`math_render.server`）
  - 与 Astro Paper 一致的排版样式（引用、脚注、定义列表等）

- **配置**
  - 通过 `everkm.yaml` 配置站点信息、社交链接、版权与文章分页
  - 通过内链从 `_home.md` 与 `_about.md` 引用首页与关于页内容
  - 社交链接在 `name` 匹配已知平台（不区分大小写）时显示内置图标，否则显示文字
